# 轻盯 1.13.3 修复与验证记录

## 修复

- 新交易日分时接口返回空数据时清空旧分时图及盘口，保留历史 K 线和历史资金图，避免将昨天的分时数据当成今天的数据。
- 主行情接口仅返回部分股票，或某只股票价格字段无效时，单独请求缺失股票的腾讯备用报价。备用源失败时保留其他正常报价和原有返回顺序。
- 提醒编辑界面使用当前规则；保存时保留最新触发时间，避免通知触发后编辑规则覆盖 5 分钟冷却记录。
- 行情时间、便签日期、工作日志、交易时段与交易日判断统一使用 Asia/Shanghai（UTC+8），不受操作系统时区影响。时间戳仍保存为 ISO 格式。
- 测试命令的排除通配符加引号，避免 Linux shell 展开。时间用例显式指定时区，行情纯函数测试模拟 Electron 模块。

## 验证

- 46 个测试在 UTC 和 America/New_York 两种机器时区下全部通过。
- TypeScript 类型检查与应用构建通过。
- NSIS 安装包和内嵌应用归档通过 7-Zip 完整性检查。
- 当前云端为 Linux 环境，尚未进行 Windows 实机安装和界面回归。
