新增自选股分组，支持新建、重命名、删除分组，并通过股票卡片的“分组”菜单手动移动股票。

- 可查看全部自选、未分组或某个自定义分组，分组显示当前可见股票数量。
- 在某个分组中添加股票，会直接放入该分组。
- 删除分组时，股票回到未分组；自选、持仓、提醒和隐藏状态保留。
- 分组及归属保存到本机，重新启动后保留；旧配置自动兼容。
- 保留中国时区和 1.13.3 行情、提醒修复。

下载 Windows x64 安装版 `MarketFloat-Setup-1.14.0-x64.exe`，按向导选择安装目录。可在安装前退出正在运行的旧版轻盯。
