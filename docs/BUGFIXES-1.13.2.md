# 轻盯 1.13.2 问题修复

检查日期：2026-10-06。保留现有功能，继续交付 Windows 安装版，不需要自行安装 Node.js。

## 已修复

- 快捷键：单独点击“应用快捷键”提交，支持交换两组按键；冲突时回退原注册，不把输入一半的字符串写入配置。启动冲突逐项尝试备用组合并提示。便签可打开设置，不提供点击进入行情的入口。
- 便签：本机数据读取完后才允许编辑；快速输入先更新界面、再顺序保存。失败会显示提示，后续保存会带上未成功保存的改动；模式切换不覆盖未保存的编辑。
- 日志：保存成功后才显示“已保存”，删除日志持久化；不恢复默认欢迎任务。
- 配置：校验 JSON 类型、有限数字、枚举及重复股票代码；写入临时文件再替换，保留 `.bak`。文件损坏时保留 `.corrupt`，尝试恢复备份。用户设置的 3 秒刷新不会在启动时强制改回 1 秒。
- 详情：快速切换股票会等待旧请求结束后加载新股票完整历史；失败可重试，不再因一个全局忙标记长时间停在“等待走势”。
- 搜索/板块：旧请求结果不能覆盖新搜索或新板块；卸载后停止更新，返回上层和隐藏自选恢复已回归。
- 行情：缺失/离线行保留最后有效价格及原时间；主力资金与备用价格分开记录时间，不把昨天资金带入新交易日；新主力值不混用旧大单分项。
- 盘口：腾讯买卖价格与数量原先读反，已纠正。东方财富列表的 `f20` 是市值而不是卖一数量，已改为详情单独请求盘口。零占位数量不伪造挂单。
- 网络：超时涵盖响应体下载，不只等待响应头；允许系统网络/独立直连重试，未关闭 TLS 证书验证。批量定时刷新与详情请求不堆积；报价失败写本机 `error.log` 便于排查。
- 数据解析：空值不转换成零，非数组/非法记录降级；无效分时记录不污染成交均价；修复港股报价时间格式，沿用来源提供的明确资金字段。
- 5/10 分钟：跨轮次积累成交、避免快照重叠重复计数，窗口终点包括中性成交；换交易日清空逐笔缓存。新样本不足时显示不足，不继续沿用旧活跃评分。
- 展示：行情和历史图都遵循红涨绿跌/绿涨红跌；图表数据变短后鼠标索引不越界；港股分时时间轴午间刻度位置修正；持仓输入拒绝非有限数，零持仓不扣最低佣金，港股详情金额标明港元。
- 窗口：恢复位置时整个窗口保持在显示器工作区；最小化窗口可由打开便签/盯盘的快捷键恢复。托盘改用随包 PNG，避免 SVG 解析为空。
- 估算口径：“可信度”改为“样本充足度”，不声称识别真实机构或量化交易者。

## 仍需注意

- 真实全局快捷键已检查 Windows 注册；界面模式通过正常 IPC 测试，回调映射通过单元测试。尚未覆盖所有其他软件占用按键、键盘 Fn 模式和物理按键场景。
- 未在干净 Windows 10/11 虚拟机逐一安装验收，也未覆盖每种多显示器/DPI/显卡组合。当前机器界面测试成功不代表所有机器都无问题。
- 免费数据源可能延迟、限流或字段变更。此次直连成功不保证朋友的不同运营商/代理/证书环境都可用。
- 资金统计只覆盖已采集成交，数据源“主力”不是账户身份认证。当前尚无交易所节假日日历，休市旧报价明确显示源时间和最近交易日。
- 安装包未配置商业代码签名证书，Windows 可能出现 SmartScreen 提示。

## 更新方法

先从托盘退出旧版，再运行 `轻盯-安装版-1.13.2.exe`。使用相同 Windows 账号和原安装目录进行更新，本机自选、持仓、提醒与便签仍从原 JSON 位置读取。安装前可自行备份 `%APPDATA%\market-float\market-float-settings.json`；当前包的应用内部名称为 `market-float`，以实际应用的 userData 路径为准，开发/测试环境可能使用不同目录。
